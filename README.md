# تطبيق مدرسة موطني لأندرويد

التطبيق الرسمي لـ **مؤسسة موطني الأساسية الأهلية المختلطة**: واجبات الأبناء، وتبليغات المدرسة، وجدول الصف، ومواعيد الامتحانات، مع إشعار فوري بكل جديد.

## التنزيل

**[تنزيل التطبيق (mawtini.apk)](https://github.com/alaaajeel/mawtini-app/releases/latest/download/mawtini.apk)**

أو من رابط المدرسة: https://mawtini-school.web.app/download/mawtini.apk

## طريقة التثبيت

1. نزّل الملف `mawtini.apk` من الرابط أعلاه.
2. افتح الملف بعد اكتمال التنزيل.
3. إن ظهرت رسالة «مصادر غير معروفة»، اضغط «الإعدادات» وفعّل «السماح من هذا المصدر».
4. اضغط «تثبيت» ثم «فتح»، وسجّل دخولك.

- يعمل على أندرويد 6 فما فوق، ويُفضّل وجود متصفح Chrome على الهاتف.
- مستخدمو آيفون: افتحوا https://mawtini-school.web.app في Safari ثم «مشاركة» ← «إضافة إلى الشاشة الرئيسية».
